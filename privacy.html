Privacy policy

Effective date: 4 October 2026. Application: AR Creator Outreach Local.

Access and use

The owner authorizes the designated Gmail mailbox. The application uses gmail.send to submit collaboration emails and replies, and gmail.readonly to verify mailbox identity, read submitted messages and inspect known collaboration threads. Gmail permissions technically cover the mailbox; runtime matching limits business processing to recorded collaboration threads.

Processed information can include email addresses, subject, plain text, message and thread identifiers and timestamps. It is used for correspondence, attribution to the responsible Instagram account, deduplication, reply notifications and refusal handling. It is not used for advertising targeting or sold.

Storage and processing

OAuth credentials are protected with Windows current-user DPAPI. Correspondence and audit records use a local SQLite database; the database itself is not encrypted by this application. The owner controls access to the Windows account and local files. The configured language model runs locally. This notice does not describe a cloud language-model integration.

Google receives Gmail API requests. A separately authorized Activepieces connection processes count-only project reports; this desktop OAuth client does not grant that separate connection access. Those reports contain counts, not creator correspondence. The owner sees validated reply notifications in the authorized project chat, without message bodies.

Retention and control

Records remain on the owner's computer until the owner removes them. Contact suppression records support the rule against repeated contact. Deleting audit or suppression evidence can require outreach to pause until history is re-established. The owner can revoke Google access through the Google Account permissions page and request removal of local records.

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements, at all times.
